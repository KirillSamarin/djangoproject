# Skystore - Django проект интернет-магазина
# Описание проекта

Skystore - это веб-приложение интернет-магазина, разработанное на Django, предназначенное для продажи цифровых продуктов таких как:

Сервисы рассылок

Telegram боты

Полезные утилиты

Веб-приложения

Микросервисы

# Функциональность
## Главная страница (/catalog/home/)
Отображение каталога товаров

Карточки товаров с описанием и ценами

Кнопки для покупки товаров
